# TRIAD — protótipo funcional

Aplicativo web mobile-first para o programa Full Body A/B/C criado para força, hipertrofia, calistenia, condicionamento e suporte à rotina de surf.

## Recursos desta versão
- Treinos A/B/C completos
- Imagem estática esquemática em cada exercício
- Botão **Ver execução** com demonstração animada
- Registro de repetições, carga e RIR
- Modo **Surf amanhã?**
- Condicionamento 30/30 com Remo ou Escalada e aviso sonoro
- Área de progresso e progressão de calistenia
- Interface responsiva, sem dependências externas

Abra `index.html` no navegador ou publique com GitHub Pages.


**TRIAD**: Strength • Conditioning • Performance.
